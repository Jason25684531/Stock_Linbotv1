# AI 與非 AI 策略比較計畫（Phase 5.2）

狀態：**只是計畫，尚未執行，不宣稱任何已證明的優劣。** 目前沒有新模型，也沒有獨立樣本，所以這四個問題今天都答不出來。

## 1. 比較的四個組別

| 組別 | 內容 | 目前狀態 |
|---|---|---|
| A 規則版 | 7 個原生策略各自只用規則選股（不用 AI） | 資料合格者已有診斷回測（原始價格基礎）；growth_momentum_breakout、quality_growth 因月營收缺公告時間而 BLOCKED |
| B 規則加 AI 排名 | 同一個規則篩選之後，用新模型的 `predict_proba` 排序 | 沒有新模型，不可執行 |
| C 因子策略 | G2/G3（3）、D5（1）、Day3（11）的家族 | 已在開發期重跑（還原價格基礎），沒有任何設定通過統計門檻 |
| D 被動基準 | 發行量加權股價報酬指數（含息）；價格基礎的組別另外對照股價指數 | 已有 |

## 2. 本輪發現的可比性問題（執行前必須先解決）

**A、B 與 C 的價格基礎不同。**
- C 組（D5、Day3、G2/G3）用的是 D3 資料集的還原價格：以官方除權息參考價與前收盤的比例逐事件還原，所以報酬已經把股利與權利調整在內，必須對照含息的報酬指數。
- A、B 組（原生策略引擎）用的是原始價格，報酬不含股利，只能對照股價指數。
- 兩者的報酬與超額報酬不可直接並排比較。執行前要把 A、B 組也改用同一份官方事件還原價，或把 C 組改用原始價格，並用同一份事件檔、同一個基準。

## 3. 共同條件（比較時所有組別一律相同）

- **股票池**：上市四位數普通股，來自每日官方 MI_INDEX 清單（point-in-time，下市股在下市前都會出現）。
- **成交**：訊號日的下一個交易日開盤價；成本採專案常數（手續費 0.1425%、證交稅 0.3%、滑價 0.1%）與 2 倍壓力成本，兩種都報。
- **持股條件**：Top N、調倉週期、權重方式相同才配對（本輪 `factor_combination_comparison.csv` 已用這個方式做單因子對多因子）。
- **成交稽核**：同一套 1%、2%、5% 成交金額占比與漲跌停鎖死旗標。
- **統計**：以淨超額報酬（相對含息基準）為證據序列；moving block bootstrap（區塊 20、2,000 次、種子固定）；Deflated Sharpe 的試驗次數計入所有被比較的設定與先前的搜尋。
- **期間**：模型訓練期間與獨立測試期間完全分開。

## 4. 期間設計

| 期間 | 用途 | 規則 |
|---|---|---|
| 新模型的 `training_data_end` 之前 | 訓練、Validation、Test（規格第 7 節） | 只用於驗收，不能作為 AI 價值的證據 |
| `training_data_end` 之後，累積滿 252 個交易日 | 獨立比較 | 開始前先登記指標與門檻；中途可以監控但不得依結果重新訓練或改門檻；已被任何回測讀取過的交易日不計入 |
| Day3 的 2026-01-01～07-28 | Day3 自己的嚴格 OOS，本輪沒有讀取 | 只有 Day3 可以使用；其他組別不得用它宣稱 OOS（原生策略的診斷與 parity 已讀過其中一部分） |
| G2/G3 的 2026-07-29 起 | Frozen Candidate 的 Fresh OOS ledger | 目前 53 個交易日、4 個月、1 次調倉，門檻 180／9／3；只有 Frozen Candidate 累積，其他設定不得借用 |

預估新模型最早能累積滿 252 個交易日是 2027-11 上旬（資料終點為 2026-10 下旬、交易日比例 0.93 的推估）。

## 5. 要回答的問題與方法

| 問題 | 比較 | 判準（事先登記，本輪不看結果） |
|---|---|---|
| AI 是否提升選股品質 | B 對 A，同一策略、同一獨立期間；配對 bootstrap 求「淨超額 Sharpe 差」的 95% 區間 | 區間下界 > 0 才能說有提升；包含 0 就寫「無法區分」。另外報告模型的前 10% 提升度與月份穩定度（規格第 9 節） |
| 多因子是否比單因子穩定 | 同參數配對的多因子對最佳單因子（已在開發期做） | 同上。開發期結果：Day3 252 組配對中 171 組無法區分、81 組多因子較差、0 組較好；G2/G3 的 12 組全部無法區分，所以目前沒有證據支持多因子較好 |
| 哪些只在特定行情有效 | 以前一日指數是否高於 200 日均線分多頭與空頭；每段至少 60 個交易日 | 兩段超額不得同時為負，樣本過短就標 UNDETERMINED；本輪三個家族在僅 84 個交易日的空頭期間都是大幅負超額，列為風險 |
| 扣成本後是否仍有正向價值 | 2 倍成本下的淨 Sharpe 與淨超額 Sharpe 都要大於 0 | 兩者都要 > 0 |
| 是否值得進入 Fresh OOS | 開發期結果通過 OD-24 全部五項，而且總報酬、成交限制、存活者偏差的認證都完整 | 只能標 `CANDIDATE_FOR_INDEPENDENT_VALIDATION`；本輪沒有任何設定符合 |

## 6. 可以做與不能做

- **可以**：用現有的規則版診斷結果與因子家族的開發期結果，確認工具、成本與統計流程可以運作。
- **不能**：用它們說明 AI 有沒有價值，也不能說任何策略「有效」。
- **前置條件**：新模型（需 Owner 簽核規格與訓練核准）、同一價格基礎、現金股利的拆分、下市退出價格、獨立樣本累積滿 252 個交易日。
