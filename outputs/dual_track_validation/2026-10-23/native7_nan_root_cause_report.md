# Native7 rules-only NaN 根本原因報告

狀態：`mean_reversion` 與 `hybrid_trend_rank` **都已用實際數值證明**（同一個估值步驟，但來源條件不同）。本報告本身不含任何補值；OD-29 核准的研究估值政策另見 `native7_valuation_fix_report.md`。

## 1. 方法

`scripts/native7_nan_trace.py` 使用與 `scripts/native7_rules_only.py` 相同的快照、引擎與設定重播策略。唯一的差別是把 `engine.daily_assets` 換成一個在寫入非有限值時立刻拋出例外的 list。所以程式停下時的現金、持股與行情，就是產生第一個無效權益值的那一刻的狀態。輸出：`native7_nan_trace_<strategy>.json`。

## 2. mean_reversion：已證明

| 項目 | 數值 |
|---|---|
| 第一個 NaN 日期 | **2023-05-11**（第 78 個交易日） |
| 前一日權益（2023-05-10） | 1,016,246.26（有限值） |
| 當日現金 | 405,428.76 |
| 持股 | 3 檔：5531（20,554 股）、**1225（3,378 股）**、8104（4,796 股） |
| 有限收盤價的持股市值 | 20,554 × 9.78 + 4,796 × 39.30 = **389,500.92**（與追蹤結果一致） |
| 1225 的成交紀錄 | 2023-04-28 訊號，2023-05-02 開盤以 59.20 買進，FILLED |
| 1225 前一有效收盤價 | 60.70（2023-05-10） |
| 1225 當日官方行情 | 開高低收全為 `--`，成交 614 股、20 筆、36,425 元 |
| 1225 隔日 | 2023-05-12 收盤 60.10（成交 1,391 股）；之後連續正常 |

**原始官方檔確認**：`MI_INDEX_20230511.json` 中 1225 那一列的開盤、最高、最低、收盤欄位都是字串 `--`。成交股數 614 不到一張，平均價 59.3。當日沒有整股成交的價格，成交量只來自零股。

**NaN 進入權益的確切位置**：`core/backtest/runner.py` 第 1140–1147 行：

```python
curr = self.get_data(sid, date_str)       # 研究路徑：NativeResearchData.bar() 回傳該列 dict
if curr:                                  # 有這一列就成立，不檢查收盤價是否有限
    last_price = curr['close_price']      # NaN
    info['last_price'] = last_price       # NaN 寫進持股的最後價格
else:
    last_price = info.get('last_price', info.get('cost', 0))
daily_asset += info['shares'] * last_price  # 3,378 × NaN → 權益 NaN
```

之後 `calculate_metrics` 對含 NaN 的報酬呼叫 `statistics.pstdev`，拋出 `AttributeError: 'float' object has no attribute 'numerator'`。這是結果，不是原因。

## 2b. hybrid_trend_rank：已證明

| 項目 | 數值 |
|---|---|
| 第一個 NaN 日期 | **2025-07-15**（第 607 個交易日） |
| 前一日權益（2025-07-14） | 434,017.41（有限值） |
| 當日現金 | 3,270.21 |
| 持股 | 3 檔：**3036（1,532 股）**、6742（3,669 股）、6153（2,229 股） |
| 有限收盤價的持股市值 | 3,669 × 54.60 + 2,229 × 14.40 = **232,425.00**（與追蹤結果一致） |
| 3036 的成交紀錄 | 2025-07-09 訊號，2025-07-10 開盤以 130.50 買進，FILLED |
| 3036 前一有效收盤價 | 133.50（2025-07-14） |
| 3036 當日官方行情 | 開高低收全為 `--`，**成交 0 股、0 筆、0 元** |
| 3036 前後 | 前後交易日每天成交 190 萬～590 萬股；2025-07-16 收盤 136.00，之後連續正常 |

**原始官方檔確認**：`MI_INDEX_20250715.json` 中 3036 那一列為 `['3036', …, '0', '0', '0', '--', '--', '--', '--', …]`。

**與 mean_reversion 的差別**：1225 當日有零股成交（614 股、20 筆）；3036 當日完全沒有任何成交，而它是每天成交數百萬股的股票。這個型態符合**單日暫停交易**，但本輪沒有快取官方暫停交易公告，因此只能標為 `PROBABLE_SUSPENSION（未經官方公告證實）`，不能直接寫成 SUSPENDED。

**NaN 進入權益的位置**：與第 2 節相同（`runner.py` 第 1142–1147 行）。若以前一收盤價估值，3036 的市值為 1,532 × 133.50 = 204,522.00，占當日權益 440,217.21 的 **46.5%**。

**分類**：VALUATION_BUG（主因，同一段程式）＋來源條件「當日零成交，疑似暫停交易」。依 OD-29 第 6 條，這類事件不能當成普通缺價：重跑結果中，原因為 `NO_VALID_CLOSE_NO_VOLUME` 的沿用事件會另外列出，並逐筆標註是否為疑似暫停交易。

## 3. 分類

| 候選 | 判定 | 證據 |
|---|---|---|
| DATA_MISSING（研究輸入漏抓） | **否** | 官方原始檔本身就是 `--`；研究資料忠實保留 |
| SUSPENDED | **否** | 當日有 20 筆零股成交；前後日整股正常交易 |
| DELISTED | **否** | 不在下市清單；之後 676 列行情中 663 列有收盤價 |
| 除權息 | **否** | 當日沒有官方除權息事件 |
| **VALUATION_BUG** | **是（主因）** | 引擎假設「有行情列就有有限收盤價」；遇到「有列但沒有整股價格」時把 NaN 帶進持股估值，而且會寫進 `last_price`，讓後續缺列的日子也延續 NaN |

**來源條件**：官方「當日無整股成交價」（`NO_REGULAR_SESSION_PRICE`）。在 2023-01-03～2026-05-14 共 1,772 列，涉及 160 檔股票、629 個交易日；其中 1,195 列有零股成交量，577 列成交量為 0。

**計數對照**：先前回報的 2,041 列是 2022-08-01～2026-05-14 的掃描（含回看期）；1,772 列只算回測期間。差額 269 列全部落在 2022-08-01～2023-01-02。若以快照實際載入的範圍（回測起日往前 160 天，2022-07-27 起）計算則是 2,047 列。

**為什麼舊的 MySQL 路徑沒碰到**：MySQL 快照中這 1,772 列有 1,760 列根本不存在，所以引擎走 `else` 分支，沿用最後價格。另有 12 列 MySQL 有這一列、官方沒有整股價格：已逐列核對，**就是** MySQL 中全部 12 列收盤價 = 0 的資料（2025-12-24 與 2025-12-26 兩天，9 檔股票），即官方 `--` 被 MySQL 寫成 0。見 `od29_valuation/invalid_close_profile.json`。

## 4. 修復方案（需要 Owner 核准，尚未執行）

**最小 core 修改（建議）**：在 `runner.py` 第 1142 行把條件改成「收盤價為有限正數」才更新 `last_price`；否則沿用最後已知的有限價格，並記錄一筆 `STALE_VALUATION` 事件（日期、股票、沿用的價格）。研究路徑與 legacy 路徑共用這段程式。MySQL 快照（1,898,811 列）沒有任何 NULL 收盤價，但有 **12 列收盤價 ≤ 0**；legacy 路徑若持有這些股票，會以 0 元估值，權益仍是有限值，但會無聲地錯誤下跌。這次修改若以「有限正數」為條件，也會改變 legacy 在這 12 列上的估值，因此需要 Owner 一併核准，並先做 legacy characterization。

- 這是**估值**（帳面市值），不是成交；下單路徑（`runner.py:735`）已經會讓 NaN 開盤價變成 UNFILLED，不受影響。
- 本質上等於「無整股成交日以前一收盤價估值」。Owner 已暫時禁止自動以前一日價格補值，因此必須由 Owner 決定是否接受這種估值口徑。
- 替代做法（不改 core）：只在研究快照中把 `NO_REGULAR_SESSION_PRICE` 的列移除，讓引擎走既有的 `else` 分支。效果相同，但等於修改研究輸入，而且隱藏了事件數，不建議。

**敏感度**：沿用前一收盤價時，對 1225 的影響是 3,378 × 60.70 = **205,044.60** 元的市值以前一日價格計一天（更正：先前版本誤寫為 205,040）；隔日恢復正常。OD-29 重跑後的沿用次數、最長天數、估值占比與敏感度見 `native7_valuation_fix_report.md`。
