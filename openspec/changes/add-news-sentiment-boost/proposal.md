# 提案：新聞情緒加分機制 + 模型重訓

## 背景 (Context)

目前系統的「新聞摘要」與「選股推薦」是完全獨立的兩條管線：
- **新聞**：`news_agent.py` 爬取鉅亨網 → Gemini 摘要 → 僅用於推播展示
- **選股**：策略篩選 → XGBoost AI 評分 → 推薦排名

這導致：即使新聞提到某產業重大利多（如半導體法說會超預期），選股結果不會有任何傾斜；反之，利空產業也不會被迴避。使用者感覺「選股與新聞脫節」。

此外，現有 AI 模型是在**含權證/ETF 汙染數據**上訓練的，需要用清洗後的乾淨數據重訓。

## 目標 (Objectives)

1. **新聞情緒加分**：讓 Gemini 從每日新聞中萃取「利多產業族群」，在選股排序時對相關個股加分，使推薦結果與當日消息面產生連結。
2. **模型重訓**：用清洗後的資料（已排除權證/衍生品）重新訓練所有策略的 XGBoost 模型，提升 AI Score 準確度。

## 設計方案

### 新聞情緒加分（方案 A — 輕量排序加權）

```
每日選股流程（2_rundaily.py）：

  策略篩選 → AI 評分 → ┐
                        ├→ 合併加分 → 最終排名 → 存入 daily_recommendations
  新聞分析 → 族群標籤 → ┘
```

**核心邏輯**：
1. `news_agent.py` 新增 `get_news_sector_boost()` 函式
   - 調用 Gemini，請其從當日新聞萃取 2~4 個「利多產業關鍵字」（如：半導體、AI、航運、綠能）
   - 回傳格式：`{"sectors": ["半導體", "AI"], "sentiment": "偏多"}`
2. `2_rundaily.py` 在 AI 評分後、存入 DB 前，對候選股做族群比對
   - 需要一張**股票 ↔ 產業對照表**（從 TWSE 產業分類或 DB 現有欄位取得）
   - 匹配到利多族群的個股，`ai_score` 乘以加分係數（如 × 1.10）
3. 加分幅度由 `config.py` 控制（`NEWS_BOOST_FACTOR = 0.10`），可調可關

**不做的事**：
- 不改動策略篩選邏輯（`filter_candidates` 不變）
- 不改模型特徵（不需要重訓才能用此功能）
- 不做個股級新聞分析（成本太高）

### 模型重訓

- 用清洗後數據（已排除 72 萬筆權證/衍生品）重跑 `3_train_model.py`
- 所有啟用策略都重訓，輸出新的 `.pkl` 模型檔

## 架構影響

| 檔案 | 變更類型 | 說明 |
|------|---------|------|
| `tool/news_agent.py` | 新增函式 | `get_news_sector_boost()` — Gemini 萃取利多族群 |
| `2_rundaily.py` | 修改 | AI 評分後加入族群加分邏輯 |
| `config.py` | 新增常數 | `NEWS_BOOST_FACTOR`、`NEWS_BOOST_ENABLED` |
| `tool/db_helper.py` | 可能新增 | `get_stock_sector(stock_id)` 產業對照查詢 |
| `3_train_model.py` | 執行 | 重訓所有模型（不改程式碼） |
| `ML_Data/pkl/*.pkl` | 更新 | 模型檔案更新 |

## 風險評估

- **Gemini API 成本**：每日多一次 API 呼叫（萃取族群），成本極低
- **加分失準**：族群比對可能不精確；設置 `NEWS_BOOST_FACTOR` 上限（最高 +15%）並可關閉
- **模型重訓**：訓練時間約 5~15 分鐘，不影響線上服務
